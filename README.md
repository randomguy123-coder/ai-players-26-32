# AI Players 26.32

An AI-player-like entity addon for Minecraft Education Edition 26.32.

## Goal
Create 16 independent AI entities that can explore, gather resources, craft items, build, fight mobs, follow player orders, and complete conditional quests.

## Requirements
- Target Minecraft Education Edition 26.32.
- Avoid experimental features.
- Prefer vanilla-style visuals and real Minecraft items.
- Use a quest system with verifiable completion conditions.
- Record errors and test results honestly.
- Never mark an untested feature as working.

## Development
1. Verify pack compatibility.
2. Test one AI entity.
3. Implement perception and movement.
4. Implement inventory, gathering, and crafting.
5. Implement quests and combat.
6. Test multiple AI entities.
7. Expand to 16 AI entities.
